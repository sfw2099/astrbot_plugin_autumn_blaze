# 🍂 AstrBot 秋焰插件 (autumn_blaze)

![Version](https://img.shields.io/badge/version-v1.3.1-blue)
![Python](https://img.shields.io/badge/python-3.10%2B-green)
![License](https://img.shields.io/badge/license-MIT-orange)

融合 **每日签到运势** + **抽老婆/强娶/求婚** + **群友羁绊档案系统** 的 AstrBot 综合插件。采用 COC (克苏鲁的呼唤) d100 骰子判定系统。

---

## 安装

### 方式一：AstrBot 插件市场
在 AstrBot WebUI 插件管理器中搜索 `autumn_blaze` 一键安装。

### 方式二：手动安装
```bash
git clone https://github.com/sfw2099/astrbot_plugin_autumn_blaze.git
```
放入 AstrBot 的 `addons` 目录，重启即可。

### 依赖
- **AstrBot** >= v4.23

## 功能

### 签到运势
| 指令 | 说明 |
|------|------|
| `/签到` / `今日运势` / `jrrp` | 生成每日运势值（1-99），AI 根据人格给予回应 |
| `/修改运势` | COC d100 骰子判定修改运势，低于分会更容易 |

### 抽老婆
| 指令 | 说明 |
|------|------|
| `/抽老婆` / `/今日老婆` | 从本群 30 天内发言的活跃群友中随机抽取今日老婆 |
| `/强娶 @某人` | COC d100 强娶判定，目标羁绊越高越难 |
| `/强娶` | 不 @ 任何人触发全体强娶（必须大成功） |
| `/我的老婆` / `/抽取历史` | 查看今日已抽取的老婆记录 |
| `/求婚 @某人` | 向对方发起求婚，对方 60 秒内回复「同意」即接受 |
| `/关系图` | 生成群友老婆关系可视化图谱 |
| `/帮助` / `/抽老婆帮助` | 查看完整帮助 |

### 管理命令
| 指令 | 说明 |
|------|------|
| `/重置记录` | (管理员) 清空今日抽取记录 |
| `/重置强娶时间` | (管理员) 重置强娶冷却 |

## COC 骰子系统

所有随机判定使用 d100 投低系统（克苏鲁的呼唤规则）：

```
投 1d100，结果 ≤ 相应阈值 → 成功
大成功: roll ≤ 5
大失败: roll ≥ 96
```

### 修改运势判定

| 当前运势 | 技能值 (100-运势) | 常规成功率 |
|------|------|------|
| 10 | 90 | 89% |
| 50 | 50 | 49% |
| 80 | 20 | 19% |
| 95 | 5 | 仅大成功可能 |

| 判定结果 | 效果 |
|------|------|
| **大成功** (roll ≤ 5) | 运势 → 随机 95~99 |
| **极难成功** (≤ 技能/5) | 运势 +15~30 |
| **困难成功** (≤ 技能/2) | 运势 +8~15 |
| **常规成功** (≤ 技能值) | 运势 +1~8 |
| **失败** | 次数 -1，运势不变 |
| **大失败** (roll ≥ 96) | 运势随机跌至 1~原值 |

骰子显示：`🎲 D100=42/90 常规成功`

### 强娶判定（个人）

| 公式 | 说明 |
|------|------|
| 技能值 | `羁绊值 + 运势值 / 3` |
| 目标羁绊 0~50 | 需常规成功 (roll ≤ 技能值) |
| 目标羁绊 51~80 | 需困难成功 (roll ≤ 技能值/2) |
| 目标羁绊 81~99 | 需极难成功 (roll ≤ 技能值/5) |

| 示例（己方羁绊50 运势80 → 技能76） | 成功率 |
|------|------|
| 目标羁绊 30 → 常规成功 | **76%** |
| 目标羁绊 70 → 困难成功 | **38%** |
| 目标羁绊 90 → 极难成功 | **15%** |

- **大成功 (roll ≤ 5)**：自动升级为全体强娶
- **大失败 (roll ≥ 96)**：羁绊 -5

骰子显示：`🎲 D100=42/76 常规成功 (需困难成功)`

### 强娶判定（全体）

必须大成功：`roll ≤ 5`。大失败羁绊 -5。

骰子显示：`🎲 D100=3/76 大成功 (需大成功)`

## 羁绊值系统

每位群友拥有独立的**对象档案**，包含以下属性：

| 属性 | 默认值 | 说明 |
|------|--------|------|
| 羁绊值 | 50 | 范围 0~99，影响强娶成功率 |
| 今日运势值 | 无 | 签到后获得，为强娶提供加成 |
| 婚配对象 | 无 | 求婚成功后绑定 |

### 羁绊值变动规则

| 行为 | 羁绊变化 |
|------|-----------|
| 每日首次求婚成功 / 被求婚成功 | **双方 +5** |
| 强娶大失败 | **-5** |

- 羁绊 < 20 时，禁止求婚和强娶
- 抽老婆、强娶成功等不再改变羁绊值

## 配置

在 AstrBot WebUI 插件配置面板中可调整：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `weighted_random` | bool | true | 启用运势高分加权 |
| `max_modify_attempts` | int | 1 | 每日修改运势次数 |
| `daily_limit` | int | 1 | 每日抽取 + 强娶上限 |
| `max_records` | int | 500 | 活跃群友记录上限 |
| `excluded_users` | list | [] | 排除用户列表（不会被抽中） |
| `force_marry_excluded_users` | list | [] | 强娶排除用户列表 |
| `whitelist_groups` | list | [] | 群聊白名单 |
| `blacklist_groups` | list | [] | 群聊黑名单 |
| `iterations` | int | 140 | 关系图迭代次数 |
| `keyword_trigger_enabled` | bool | false | 关键词触发（无需 `/` 前缀） |
| `keyword_trigger_mode` | string | exact | 匹配模式：exact/starts_with/contains |
| `auto_set_other_half` | bool | false | 抽到老婆时自动给对方绑定 |
| `auto_withdraw_enabled` | bool | false | 定时自动撤回消息 |
| `auto_withdraw_delay_seconds` | int | 5 | 自动撤回延迟（秒） |
| `allow_marry_bot` | bool | false | 允许抽取/强娶机器人 |
| `at_waifu` | bool | false | 是否 @ 抽到的老婆 |

## 数据存储

插件数据在 `<AstrBot数据目录>/autumn_blaze/` 下：

| 文件 | 说明 |
|------|------|
| `wife_records.json` | 每日老婆抽取记录 |
| `active_users.json` | 活跃用户池 |
| `profiles/{uid}.json` | 每位群友的羁绊值档案 |
